# 亚空间什一税

一个不依赖第三方包的战锤 40K 同人联机桌游原型。玩法保留投骰移动、领地争夺和玩家互动，但加入了亚空间压力、阵营能力、入侵与动态胜利条件。

## 运行

需要 Node.js 18 或更高版本。

```powershell
cd C:\Users\Administrator\Documents\Codex\2026-09-22\warp-tithe
npm.cmd start
```

打开 `http://localhost:3210`。同一局域网中的玩家可以使用运行服务器的电脑 IP 访问，例如 `http://192.168.1.20:3210`。

需要临时公网入口时，保持服务器运行，并在另一个终端执行：

```powershell
npm.cmd run share
```

终端会返回一个 `https://...lhr.life` 地址，把它发给其他玩家即可。该隧道不需要访问者输入公网 IP 或隧道密码。公网房间代码仍然承担加入门槛，但当前版本没有账号系统，不要把房间代码公开发布。

测试：

```powershell
npm.cmd test
```

## 当前规则

- 2 到 4 名玩家，各自选择帝国、混沌、兽人或灵族。
- 投掷单颗 D12 在 32 格星区棋盘上移动。
- 无主世界可以花费影响力占领，己方世界可以升级，敌方世界可以缴纳什一税或入侵。
- 入侵比较 `进攻方 1D6 + 阵营加成` 与 `防守方 1D6 + 世界等级`。防守方更高时守住领地，进攻方还要支付战争物资损失和赔款；平局时双方各扣战争物资损失，世界降一级并在三个回合后恢复；进攻方更高时夺取世界。
- 领地会在每轮开始时提供影响力。
- 投出 12 与部分特殊区域会提高亚空间压力。
- 压力达到 4、8、12 时触发混沌事件，达到 16 时按统治点结算。
- 率先达到 12 统治点通常直接获胜。
- 房主可以在游戏结束后重新开始。

## 技术结构

- `server.js`：HTTP API、房间状态、SSE 实时推送和规则实现。
- `public/app.js`：客户端状态渲染、棋盘交互和实时连接。
- `public/styles.css`：响应式棋盘和界面样式。
- `public/assets/`：原创星区背景和徽记。
- `Dockerfile`：生成可部署到云平台的 Node.js 服务。
- `render.yaml`：Render Web Service 免费部署配置；需要常驻时再升级到 `starter`。

## 固定域名部署

固定域名不能由匿名临时隧道提供，需要选择以下一种方式：

1. 使用 Cloudflare Named Tunnel，并提供一个已接入 Cloudflare 的域名。公网地址固定，但运行游戏的电脑必须保持开机。
2. 部署到 Render 等长期托管平台。平台会提供固定子域名，免费实例可能在闲置后休眠；升级到 `starter` 或更高配置可以保持常驻。
