# 亚空间什一税

一个不依赖第三方包的战锤 40K 同人联机桌游原型。玩法保留投骰移动、领地争夺和玩家互动，并加入亚空间压力、入侵与动态胜利条件。当前版本已关闭所有阵营技能，阵营只影响名称、颜色和外观。

## 运行

需要 Node.js 18 或更高版本。

```powershell
cd C:\Users\Administrator\Documents\Codex\2026-09-22\warp-tithe
npm.cmd start
```

打开 `http://localhost:3210`。同一局域网中的玩家可以使用运行服务器的电脑 IP 访问，例如 `http://192.168.1.20:3210`。

需要临时公网入口时，保持服务器运行，并在另一个终端执行：

```powershell
npm.cmd run share
```

终端会返回一个 `https://...lhr.life` 地址，把它发给其他玩家即可。该隧道不需要访问者输入公网 IP 或隧道密码。公网房间代码仍然承担加入门槛，但当前版本没有账号系统，不要把房间代码公开发布。

测试：

```powershell
npm.cmd test
```

## 当前规则

- 2 到 6 名玩家，可以选择帝国、混沌、兽人、灵族、太空死灵或钛帝国；阵营只影响名称、颜色和外观，不提供任何种族技能或数值。
- 每名玩家开局拥有 600 影响力。
- 房主可以在准备阶段添加最多 5 个 AI，AI 会自动准备并在自己的回合占领、升级、缴税或入侵。
- 远征开始时，每名玩家会从全部 72 个星球中随机抽取一个互不重复的出生地，开局不会触发落点效果。
- 每名玩家还会从八项初始技能池中随机抽取一项互不重复的技能：领地收益 +25%、入侵同点获胜、随机事件损失减半、占领和升级费用 -30%，以及偷取影响力、操纵亚空间压力、远程商店与随机传送、8 格范围降低星球等级四项主动技能。
- 投掷单颗 D12 在 72 格三星系棋盘上移动。索拉里昂星区、阿尔法核心和伽马核心各自形成一座 24 格三角形航线。
- 三座星系之间通过成对的星门顶点跃迁；没有跨星系连接的顶点改为星际商店。
- 三座星系各有一个没有跨星系连接的顶点，共三座星际商店；抵达后可以消耗影响力购买道具。后期亚空间事件触发后，商店会全部坍缩为随机传送点并停止出售道具。
- 每座商店在每轮刷新 3 件不重复道具，每名玩家每回合最多购买 1 件。道具价格和效果为：亚空间抑制卡 60（压力 -2）、攻城卡 90（下一次入侵点数 +2）、升级卡 140（免费升级 8 格内己方星球）、传送卡 150（将 8 格内玩家传送到任意星球）、静止卡 150（目标两回合无法移动）、重生卡 200（随机重置初始技能）、万能骰子 200（指定下一次移动点数，不用于入侵）。
- 每个领地以圆形星球显示，并根据巢都、铸造、圣祠、死亡、处女、墓穴、遗物、网道、亚空间和星门背景使用不同行星材质。
- 无主世界可以花费影响力占领，己方世界可以升级，敌方世界可以缴纳什一税或入侵。
- 入侵比较 `进攻方 1D6` 与 `防守方 1D6 + 世界等级`。防守方更高时守住领地，进攻方还要支付战争物资损失和赔款；平局时双方各扣战争物资损失，世界降一级并在三个回合后恢复；进攻方更高时夺取世界。
- 领地会在每轮开始时提供影响力。
- 投出 12 与部分特殊区域会提高亚空间压力。
- 压力上限为 40。达到 8 触发恐虐狂潮，随机摧毁三个领土等级；达到 16 触发色孽之祸，随机侵蚀三个非传送地块并禁锢踏入者；达到 24 触发奸奇之谋，使所有商店停售并变为随机传送点；达到 32 触发纳垢降临，纳垢本体行动五回合并把侵占领土化为无主废土；达到 40 时触发大裂痕并按统治点结算。
- 率先达到 20 统治点通常直接获胜。
- 房主可以在游戏结束后重新开始。

## 技术结构

- `server.js`：HTTP API、房间状态、SSE 实时推送和规则实现。
- `public/app.js`：客户端状态渲染、棋盘交互和实时连接。
- `public/styles.css`：响应式棋盘和界面样式。
- `public/assets/`：原创星区背景和徽记。
- `Dockerfile`：生成可部署到云平台的 Node.js 服务。
- `render.yaml`：Render Web Service 免费部署配置；需要常驻时再升级到 `starter`。

## 固定域名部署

当前固定公网地址由 Netlify 托管：

```text
https://warp-tithe.netlify.app
```

Netlify 版本使用 Blobs 持久化房间，前端每 1.2 秒轮询最新房间状态。部署文件包括：

- `netlify.toml`：静态资源、Functions 和 `/api/*` 路由。
- `netlify/functions/api.mjs`：房间 API、线上游戏规则和 Blob 持久化。
- `netlify/functions/game.js`：由 `server.js` 自动生成的共享游戏逻辑。

`tools/build-worker-game.js` 会同时生成 Cloudflare Workers 和 Netlify Functions 使用的游戏核心。修改 `server.js` 后运行：

```powershell
node tools\build-worker-game.js
```
